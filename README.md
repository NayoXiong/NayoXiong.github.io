# Jiawei Xiong — Academic Website

Personal academic website (multi-page).
Live at: **https://nayoxiong.github.io**

## Pages

| File | What it is |
|------|-----------|
| `index.html` | Home — who I am, education, a publications summary, and profile links |
| `publications.html` | Book, journal articles, chapters, proceedings, R packages, dissertation |
| `talks.html` | Selected conference talks & panels |
| `awards.html` | Awards & honors |
| `editorial.html` | Editorial board & guest editor roles |
| `service.html` | Professional service |
| `assessments.html` | Large-scale assessment programs |
| `media.html` | Selected media coverage |

## Shared files (used by every page)

| File | What it is |
|------|-----------|
| `styles.css` | Colors, fonts, layout, light/dark themes |
| `script.js` | Menu, dark-mode toggle, small interactions |
| `robots.txt` | Tells search engines they may index the site |
| `sitemap.xml` | Lists every page so search engines can find them |
| `assets/profile.jpg` | Header photo |
| `assets/favicon.svg` | Little "JX" icon shown in the browser tab |


## How to update the site later

1. Open the relevant page file (e.g. `publications.html` to change publications).
   To add an entry, copy an existing `<li>...</li>` line in the right list and edit the text.
2. If you add or remove a whole page, update the navigation menu (the `<nav>` block near
   the top) in **every** page file, and add the page to `sitemap.xml`.
3. Save, then upload the changed file(s) to GitHub, replacing the old ones.
   The live site updates within a minute or two.
